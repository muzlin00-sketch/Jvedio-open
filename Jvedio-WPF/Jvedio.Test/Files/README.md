# 测试素材

本目录原本放两个测试素材包（`Files.7z`、`NFO.7z`，共约 40 MB），
它们是从真实影片库抽出的样本，**不随本仓库分发**：

- 体积大，且属于个人媒体库数据，不适合公开；
- 测试工程不依赖它们也能编译，只有个别用例在运行时需要。

要跑依赖素材的用例，把同名文件放到本目录即可：

```
Jvedio-WPF/Jvedio.Test/Files/Files.7z
Jvedio-WPF/Jvedio.Test/Files/NFO.7z
```

素材格式：`Files.7z` 为若干视频文件（用于扫描/识别用例），
`NFO.7z` 为对应的 NFO 元数据文件（用于解析用例）。
