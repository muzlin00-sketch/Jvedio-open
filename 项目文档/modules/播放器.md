# 播放器

本地播放走 `<video>` 直连 `/stream/{dataId}`，服务端支持 Range 请求（`WriteFileRange`）。

## 播放

- `video.preload = 'metadata'`；`autoplay` + `playsInline`，并补
  `webkit-playsinline` / `x5-playsinline` 兼容 iOS 与微信内置浏览器。
- `error` 事件弹提示：浏览器不支持的格式说明需要服务端转码。
- 流地址在开启访问口令后要拼令牌（`withToken()`）。

## 手势

全部参数见[设计规范·手势与触摸](../设计规范.md)。实现要点：

| 动作 | 行为 |
|---|---|
| 单击 | 切换控件显隐（300ms 延迟等双击判定） |
| 双击左 / 右 | −10s / +10s |
| 水平滑动 | 按比例快进快退，松手才 seek |
| 垂直滑动 | 忽略（不抢页面滚动） |
| 底部进度条拖动 | 精确 seek |

**滑动结束必须屏蔽紧随的 click**（350ms 窗口，[踩坑约定 #10](../踩坑约定.md)），
否则滑一次会连带切一下控件。

**快进用比例映射**，不用固定像素秒数：

```
Δ秒 = (水平位移 / 视频显示宽度) × 总时长
```

这样"滑半个屏幕"在不同片长下都约等于走一半内容。

滑动过程中只更新浮层提示，不调 `currentTime`；松手一次性写入，避免拖动中反复 seek。

## 控件

- 控件层 `.vc` 与滑动提示 `.vc-swipe-tip` 在播放页内（`z-index` 5 / 6）。
- 拖进度条时在 `window` 上绑 `pointermove/pointerup`，**必须统一 cleanup**
  （进入、退出播放页、停止投屏三处调用），否则监听累积导致重复 seek
  （[踩坑约定 #13](../踩坑约定.md)）。

## 与投屏的关系

播放页是投屏远程面板的宿主。进入投屏后视频区被远程面板替换，进度条与按钮改为代理远端。
详情与退出逻辑见[投屏](投屏.md)。

## 关闭

`closePlayer()` 负责：清理拖动监听、解绑列表滚动、恢复历史。
从详情页进来时用 `replaceState` 而非 `pushState`，避免返回键要按两次
（[踩坑约定 #12](../踩坑约定.md)）。
