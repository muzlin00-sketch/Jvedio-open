# 访问口令

局域网服务的访问控制。代码：`Core\Lan\LanAuth.cs`（令牌）、`LanServer.cs`（接口与校验）、
`Windows\Window_Settings.xaml(.cs)`（桌面端设置）、`index.html`（登录遮罩）。

## 为什么不是账号体系

单机媒体库没有多用户场景，多账号只会扩大攻击面。**只做一个访问口令，每台设备输一次。**

明确不做：注册、找回密码、验证码、口令强度规则、"记住我"勾选框、登录有效期选项。

## 数据流

```
桌面端设置页 ──写入──> Settings.LanAccessPassword
                          ├─> 启动时 Auth.SetPassword()      （Window_Main.InitLanServer）
                          └─> 保存时 Auth.SetPassword()      （立即生效，无需重启）
                                    │
手机 GET /api/auth/status ──────────┤
   ├ required=false        ──> 直接启动，完全无感
   ├ authenticated=true    ──> 直接启动
   └ 否则                  ──> 显示登录遮罩
              POST /api/auth/login {password} → {token}
                          └─> localStorage，之后自动带上
```

**默认不启用**。升级后行为与原来完全一致，需要时在桌面端勾选并设口令。

## 令牌格式

自包含 HMAC 签名，无服务端会话表：

```
base64url(过期时间|随机数) + "." + base64url(HMAC-SHA256)
```

- 密钥由口令派生 → **改口令即让所有旧令牌失效**，不需要额外"全部下线"逻辑。
- 重启服务后旧令牌仍有效（密钥没变）。
- 有效期 365 天，单机自用不必频繁重登。

携带方式三种，按优先级：`Authorization: Bearer xxx` → 查询串 `?token=xxx`
（给 `<img src>` / `<video src>` 用，它们带不了头）→ `Cookie: jvedio_token=xxx`。

## 鉴权边界

| 路径 | 是否校验 |
|---|---|
| `/`、`/api/auth/status`、`/api/auth/login`、`/api/auth/logout` | 不校验（否则登不进去） |
| `/api/libraries`、`/api/videos`、`/api/video/*`、`/api/filters` 等 | 校验 |
| `/api/rate/*`、`/api/watched/*` | 校验（写操作，且只接受 POST） |
| `/image/*` | 校验 |
| `/stream/*` | 校验，但**另接受投屏临时令牌** |

## 投屏临时令牌

投影仪拉流时无法携带 Cookie。若完全放开 `/stream/`，知道 `dataId` 就能下载整部片；
若强制校验，投屏必然坏掉。

做法：投屏时签发**绑定 `dataId`、十分钟有效**的临时令牌，拼在流地址上：

```csharp
if (_Auth.Enabled) {
    string castToken = _Auth.IssueCastToken(dataId);
    mediaUrl += "?cast=" + WebUtility.UrlEncode(castToken);
}
```

`/stream/` 的校验顺序：投屏临时令牌 → 普通访问令牌 → 拒绝。

## 防暴力破解

按 IP 计失败次数，连续 10 次锁 5 分钟。口令比较用常量时间算法，避免通过响应时间差逐字节猜。

## 桌面端设置

设置页「手机网页版」区块：启用勾选框 + 口令输入框 + 状态提示。
勾了启用但口令少于 4 位按未启用处理并提示。

口令明文存在本机 `app_configs.sqlite` 里——这是单机场景的合理取舍：文件就在用户自己电脑上，
加密不提升实际安全性，反而让"忘记口令"变成无解问题。真正的防线是局域网边界与失败限速。

## 排障

- **改了配置不生效** → 先读[踩坑约定 #2](../踩坑约定.md)。`int` 类型的配置项曾因反射赋值
  失败而恒定用默认值；端口"被占用"但端口其实空着，就是读到了旧默认值。
- **登录后图片/视频 401** → 检查地址是否拼了 `?token=`（`withToken()`）。
- **投屏拉流 401** → 检查是否签发了投屏临时令牌，以及流地址里是否带了 `?cast=`。
- **网页一直要求登录** → `localStorage` 被清或令牌过期；改过口令也会让旧令牌全失效。
