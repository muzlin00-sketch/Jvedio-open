# 刮削与插件

刮削 = 拿文件名或番号去站点上把标题、演员、封面、简介取回来填进影片库。
本文只讲**怎么配、怎么排查**；内部实现与坑见 [踩坑约定](踩坑约定.md) 第 31~33 条。

## 两条路径，顺序固定

| | 内置刮削器 | 番号插件 |
|---|---|---|
| 面向 | 普通影片（电影 / 剧集 / 动画） | 番号类（`SSIS-001`、`FC2-PPV-1234567`） |
| 来源 | 豆瓣 / TMDB / Bangumi，源码在仓库里 | `plugins/crawlers/<插件>/` 下的 DLL |
| 要 Key 吗 | TMDB 要自己申请，豆瓣与 Bangumi 免 Key | 都不要 |
| 什么时候跑 | **先跑**，出结果就直接用 | 内置没结果时才跑 |

番号插件之间也是「谁先成功用谁」：多个源都启用时，按插件顺序一个个试，第一个返回有效结果就停，
所以**不要无脑全开**，慢且容易撞上被墙的站。

## 内置刮削器（普通影片）

位置：**设置 → 网络 → 内置刮削器**。

- 豆瓣、Bangumi 免 Key，勾上就能用。
- TMDB 要 Key：到 <https://www.themoviedb.org/settings/api> 免费申请，填进「TMDB API Key」，不填就跳过 TMDB。
- 豆瓣可选填 Cookie，填了能减少「无权限」的情况；不填多数情况也能刮。
- 文件名越规矩越好：`让子弹飞 (2010).mp4`、`[S01E02] 进击的巨人.mkv`。单集文件会优先问 Bangumi
  （豆瓣的搜索接口只返回电影类条目，问它拿不到 TV 版）。

## 番号插件（自带 4 个，开箱可用）

仓库和发布包都带了四个番号插件，都在 `plugins/crawlers/` 下：

| 目录 | 站点 | 默认状态 | 说明 |
|---|---|---|---|
| `bus` | JavBus <https://www.javbus.com/> | **启用** | 免 Cookie 一般就能出结果 |
| `db` | JavDB <https://javdb.com/> | 关闭 | 站点要过 18 岁确认，建议贴 `over18=1` 的 Cookie |
| `library` | JavLibrary <https://www.javlibrary.com/cn/> | 关闭 | 站点慢、常挡直连，能开就贴 Cookie |
| `fc2` | FC2 PPV DB <https://fc2ppvdb.com/> | 关闭 | 只对 `FC2-PPV-xxxxxxx` 这类番号有用 |

**启用步骤**：设置 → 刮削器 → 勾选对应插件 → 地址已预填，需要的话改 → 有 Cookie 就贴进 Cookie 框 →
点「测试」确认可用 → 应用。

**Cookie 怎么取**：浏览器打开该站点并通过年龄确认，F12 → Network → 随便点一个请求 →
复制请求头里的 `Cookie` 整串。Cookie 会过期，刮不动了先换 Cookie。

**多源怎么选**：日常用 `bus` 一个就够。某些番号 JavBus 没有（比如 FC2、素人系列），再按需开 `db` 或 `fc2`。

## 插件中心

主界面右上角菜单 → **插件**。可以安装 / 更新 / 卸载爬虫与主题插件，列表来自上游的
[hitchao/Jvedio-Plugin](https://github.com/hitchao/Jvedio-Plugin)。仓库自带的四个插件在这里也能看到，
显示的版本就是包里的版本。

插件目录结构（自己写插件时照这个来）：

```
plugins/crawlers/<插件目录名>/
├── main.json          插件元数据，PluginName / 版本 / Files
├── <Xxx>Crawler.dll   爬虫本体，实现 CommonNet.Crawler.ICrawler
├── config.json        {"enabled": true}
├── readme.md
└── images/plugin.png  插件中心里显示的图标
```

目录名就是插件 ID 的后半段：`crawlers/bus` → `crawler/bus`。

## 刮削失败怎么查

| 现象 | 先查这里 |
|---|---|
| 提示「没有可用的刮削器」 | 插件没被加载（目录缺 `main.json` 或 DLL），或源没配好（要 `Enabled` + `Available = 1` + `Url` 非空） |
| 插件在、但一直失败 | Cookie 过期 / 站点被墙 / 番号没识别对（看文件名，见下） |
| 普通影片刮到错的条目 | 文件名缺年份，或标题里混了压制组标记；改文件名重试 |
| 番号被截断（`ABC-123-ch` 识别成别的） | 后缀白名单只剥 `C/CH/CHS/CHT/U/UC/HD/FHD`，`HRV-030A` 这类合法尾字母会保留 |

番号识别规则：优先用影片的 VID 字段；没有就由 `Core/Identity/Identify.cs` 从文件名里按多组正则抓
（`ABC-123`、`ABC123`、`123ABC-456`、`FC2-PPV-1234567` 等形态都覆盖），抓不到再看标题。
纯数字（`123456`）不会被当成番号。后缀白名单只剥 `C/CH/CHS/CHT/U/UC/HD/FHD`，`HRV-030A` 这类合法尾字母会保留。
