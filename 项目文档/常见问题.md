# 常见问题

按「现象 → 先查什么」写，逐条都能直接动手。刮削相关单独见 [刮削与插件](刮削与插件.md)。

## 安装与卸载

**安装版装到哪了**
`%LOCALAPPDATA%\Programs\Jvedio`（在资源管理器地址栏粘贴即可打开）。装在这里是因为程序要在自己目录下
写 `data\`，装在 Program Files 会因权限失败。开始菜单里有快捷方式，卸载也在里面。

**怎么彻底卸载**
设置 → 应用 → Jvedio → 卸载，或开始菜单里的「卸载 Jvedio」。
**卸载只删程序文件，不删 `data\`**——影片库、封面、日志都在里面。确认不要了再手动删该目录。

**安装时提示没有 .NET Framework 4.7.2**
只是提示，安装会继续。装好 .NET 之后就能启动；Win10 1803 以上系统自带，一般不会遇到。

## 启动

**双击没反应 / 一闪而过**
需要 .NET Framework 4.7.2 或更高（Win10 1803 之后系统自带）。第一次运行若被 SmartScreen 拦，
点「更多信息 → 仍要运行」；杀软误报可以把这个目录加白。

**启动后停在「欢迎使用 Jvedio」不动、手机也连不上**
这是选库页，不是卡死。双击列表里的库就能进主界面。如果每次都要手动点，把数据库里
`WindowConfig.Settings` 的 `OpenDataBaseDefault` 置为 `true`（见 [踩坑约定](踩坑约定.md) 第 30 条）。

**端口被占用**
设置 → 局域网 改端口。默认端口见同一页；改完要点应用，然后重启服务。

## 手机端

**手机打不开**
1. 手机和电脑必须同一个 Wi-Fi / 局域网，**不能走移动数据**。
2. 用电脑上显示的局域网 IP，不要用 `127.0.0.1`。
3. Windows 防火墙第一次会弹窗，选「允许专用网络」；漏点过就在防火墙里放行 `Jvedio.exe`。
4. 电脑装了 VPN / 虚拟机网卡时，程序会自动挑「真实局域网网段」的地址（会排除 VPN 那种点对点地址），
   一般不用管；如果显示的地址明显不对（比如是 VPN 网段），先断开 VPN 再看。

**换了 Wi-Fi / 换了地方，地址变了**
地址是**每次显示时现算**的，不用重启程序。重新打开一次设置页，或看启动时的提示，拿新地址即可。
已经连着的手机刷新一下页面；浏览器收藏了旧地址的，改成新地址。

**提示口令错误**
口令在「设置 → 局域网」里，一台设备输一次就记住。改了口令要清浏览器站点数据或换设备重进。

**投屏搜不到设备**
手机和电视要在同一网段；部分电视只接受 DLNA 推流不接受远程面板，换用「投屏 → 推流」。

## 播放

**黑屏 / 只有声音**
多半是 HEVC（H.265）或 10bit 编码。桌面端装一个解码包（如 HEVC 视频扩展），或把文件转成 H.264。

**进度不记录 / 续播失效**
续播按数据库里的观看进度走。手动移动或改名过文件后，路径对不上就记不住——重新扫描一次。

## 数据与备份

**数据存在哪**
程序目录下的 `data\<用户名>\`：`app_configs.sqlite`（配置）、`*.sqlite`（影片库）、`log\`（日志）、封面与截图。
**整个 `data` 目录复制走就是完整备份**；换机器把程序目录和 `data` 一起拷过去即可。

**换库 / 多库**
设置 → 数据库 可以建多个库、切换、重命名。库之间数据独立。

## 番号与刮削

**番号识别不对**
见 [刮削与插件](刮削与插件.md) 末尾的识别规则；文件名里保留 `ABC-123` 这种形态最稳。

**刮削没反应 / 提示没有可用的刮削器**
先看 [刮削与插件](刮削与插件.md) 的「刮削失败怎么查」表，90% 是插件没加载或源没配。

## 还不行

日志在 `data\<用户名>\log\` 下，按日期命名。提 issue 时带上：现象、复现步骤、对应时间段的日志片段、
程序版本（关于页面）。
