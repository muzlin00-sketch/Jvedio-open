# 设计规范

移动端网页（`Jvedio-WPF\Jvedio\Resources\Web\index.html`）的现行规则。
桌面端 WPF 主题另见 [THEME-GUIDE.md](../THEME-GUIDE.md)，设计方向背景见 [UI-REDESIGN.md](../UI-REDESIGN.md)。

规则只写**当前生效的判据**；改版提案属于历史，不进本文。

## 配色

全部走 CSS 变量，定义在 `:root`。**不要写硬编码色值**——换主题时改不动。

| 用途 | 变量 | 值 |
|---|---|---|
| 背景（底层 / 次层 / 浮起） | `--bg-base` / `--bg-subtle` / `--bg-raised` | `#F0F0EB` / `#F7F7F3` / `#FFFFFF` |
| 侧栏底色 | `--bg-side` | `#EDF3EF` |
| 文字（主 / 次 / 弱） | `--fg-primary` / `--fg-secondary` / `--fg-muted` | `#3A3A35` / `#6E6E66` / `#96968D` |
| 边框（常规 / 极淡） | `--border` / `--border-soft` | `#DCDCD5` / `#E7E7E1` |
| 强调色（唯一） | `--accent` / `--accent-deep` / `--accent-soft` / `--accent-wash` | `#87A48E` / `#5A7A63` / `#C9DBD0` / `#EDF3EF` |
| 标签 | `--tag-bg` / `--tag-fg` | `rgba(135,164,142,.16)` / `#5A7A63` |

两条口径：

- **不用纯黑**。正文用深暖灰 `#3A3A35`，纯黑在大面积浅底上显硬。
- **强调色全站唯一**，是灰调鼠尾草绿。要表达"更重要"时靠字重、层级和留白，不加第二种彩色。

## 尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 间距（4px 基准） | `--sp-1` … `--sp-6` | 4 / 8 / 12 / 16 / 20 / 24 |
| 圆角 | `--r-sm` / `--r-md` / `--r-lg` | 6 / 10 / 14 |
| 字号 | `--fs-caption` / `--fs-body` / `--fs-body-lg` / `--fs-title` | 12 / 14 / 16 / 18 |
| 阴影 | `--shadow-card` / `--shadow-lift` | 见 `:root` |

安全区用 `--safe-top` / `--safe-bottom`（`env(safe-area-inset-*)`），不要用固定 padding 顶刘海。

## 长度单位用 cqi，不用 vw

`.app` 声明 `container-type: inline-size`，子元素用 `--u: 1cqi`。

原因：`cqi` 是**查询容器内容宽度的 1%**，天然排除滚动条，不会出现"右边缘卡片被截断"；
`vw` 含滚动条宽度，会在有滚动条时算宽。这条不是风格偏好，是修出来的。

## 卡片网格

```css
grid-template-columns: repeat(auto-fill, minmax(var(--card-min), 1fr));
```

- 列数由「可用宽度 ÷ `--card-min`」自然决定，不写死 2/3/4 列。
- 用 `minmax(MIN, 1fr)` 而非 `minmax(MIN, MAX)`：保证卡片永远 ≥ MIN，列数只由 MIN 决定。
- 封面比例 `aspect-ratio: 735 / 1000`。这个值来自实测：500 张 `SmallPic` 抽样中位 0.7350、
  众数 0.73（450/500），最小 0.7034。改比例前先重新抽样，别凭感觉调。

## 层级

顺序固定，新增浮层先在下表里找位置，别随手写大数字。

| 层 | 值 |
|---|---|
| 播放器控件 `.vc` / 滑动提示 | 5 / 6 |
| 顶栏 `.topbar` | 100 |
| 播放页 `.player-page` | 200 |
| 详情页 `.detail-page` | 210 |
| 底部面板 `.sheet-mask` / `.sheet` | 240 / 250 |
| 投屏设备面板 `.cast-mask` / `.cast-sheet` | 260 / 261 |
| 顶部进度条 / 截图查看器 | 300 / 320 |
| Toast | 400 |
| 登录遮罩 | 500 |

**详情页（210）高于播放页（200）**——从详情页进播放或投屏时，必须先关掉详情页并解锁滚动，
否则远程面板会被盖住（[踩坑约定 #12](踩坑约定.md)）。

## 手势与触摸

| 参数 | 值 | 说明 |
|---|---|---|
| 滑动判定阈值 | `SWIPE_THRESHOLD = 12` | 水平位移超过 12px 才认定为滑动，低于则当点击 |
| 单击延迟 | 300ms | 等双击判定，超时才执行单击（切控件显隐） |
| 控件自动隐藏 | 900ms | 单击后延时隐藏 |
| 滑动后屏蔽 click | 350ms | `Date.now() - swipe.lastEndAt < 350` |
| 双击左/右 | ±10s | — |

**快进映射用比例，不用固定像素**：

```
Δ秒 = (水平位移 / 视频显示宽度) × 总时长
```

固定"每过 1px 前进 N 秒"在长片和短片上体验完全不同；按比例映射才能让"滑半个屏幕 ≈ 走一半内容"。

可点区域（卡片、封面）统一加：

```css
touch-action: manipulation;        /* 去 300ms 延迟 + 禁双击缩放 */
-webkit-user-select: none;
user-select: none;
-webkit-touch-callout: none;       /* 长按不弹图片菜单 */
-webkit-tap-highlight-color: transparent;
```

不加这两样的后果是用户连点会触发双击缩放、长按弹保存菜单，感知上是"页面刷新了"
（[踩坑约定 #9](踩坑约定.md)）。

## 点击分区

一张卡片分两种行为：**封面 → 直接播放**（最常用，少一次跳转）；**文字区 → 详情页**。

判定用 `cover.contains(e.target)`，不要靠 DOM 层级或坐标猜（[踩坑约定 #8](踩坑约定.md)）。

## 空态与加载

- 图片加载完成前保持灰底，失败则整块隐藏，不留空白方块。
- 列表用骨架占位，不要空白等数据。
- 长列表滚动区需要 `min-height: 0` 才能内部滚动（[踩坑约定 #11](踩坑约定.md)）。
