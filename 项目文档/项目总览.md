# 项目总览

Jvedio 维护版：在原 Jvedio 基础上修复构建、补齐移动端网页与投屏能力。
上游 `hitchao/Jvedio`（GPL v3）已于 2026-04 归档为只读。

## 技术结构

| 层 | 技术 / 责任 |
|---|---|
| 桌面端 | WPF、.NET Framework 4.7.2、`LangVersion 7.3` |
| 核心库 | `Jvedio.Core`，`netstandard2.0`，可跨平台复用 |
| 局域网服务 | 自建 `TcpListener` HTTP 服务（`Core\Lan\LanServer.cs`），无第三方 Web 框架 |
| 移动端网页 | 单文件 `index.html`（HTML + CSS + 原生 JS，无构建步骤），约 4700 行 |
| 投屏 | DLNA / UPnP AVTransport（`Core\Lan\Dlna.cs`） |
| 数据 | SQLite：`app_datas.sqlite`（影片库）、`app_configs.sqlite`（配置） |

## 路由对照

`LanServer.Route()` 是唯一入口，路径在 `TrimEnd('/')` 之后匹配。

| 路由 | 用途 |
|---|---|
| `/`、`/index.html` | 移动端网页 |
| `/api/libraries` | 影片库列表 |
| `/api/videos?page=&pageSize=&dbId=&keyword=&sort=` | 分页列表与搜索 |
| `/api/video/{dataId}` | 详情 |
| `/api/random` | 随机推荐 |
| `/api/similar/{dataId}?count=` | 相似推荐 |
| `/api/filters` | 筛选项 |
| `/image/{small\|big\|preview}/{dataId}` | 封面与截图 |
| `/image/actor/{actorId}` | 演员头像 |
| `/stream/{dataId}` | 视频流（支持 Range） |
| `/api/rate/{dataId}` | 评分（POST） |
| `/api/watched/{dataId}` | 标记已看（POST） |
| `/api/auth/status`、`/api/auth/login`、`/api/auth/logout` | 访问口令 |
| `/api/cast/devices` | 投屏设备发现 |
| `/api/cast/play/{dataId}`、`pause`、`resume`、`stop`、`seek`、`status` | 投屏控制 |

写操作只接受 POST（防止浏览器预取误触发）。鉴权开启后，除 `/`、`/api/auth/*` 外都要令牌；
`/stream/` 另接受投屏临时令牌（见 [modules/访问口令](modules/访问口令.md)）。

## 文档体系

**标题给人看，正文给 AI 看**：正文写稠密的事实与判据，不写动机（动机属于历史记录）。
结构不求稳定，功能增删时直接拆并归档，不为好看保留空壳。

| 层 | 位置 | 回答什么 | 增改方式 |
|---|---|---|---|
| 入口约定 | [AGENTS.md](../AGENTS.md) | 干这件事先读哪份、有哪些红线 | **「按任务读哪份」的唯一真源** |
| 总览 | 本文 | 结构、路由、文档体系 | 结构变化时改 |
| 功能 | `modules/*.md` | 某功能怎么实现、坑在哪、改哪里 | 功能改动时同批更新 |
| 使用说明 | [刮削与插件](刮削与插件.md)、[常见问题](常见问题.md) | 用户视角：怎么配、出问题先查哪 | 配置项或插件机制变化时同批更新 |
| 跨模块 | [部署](部署.md)、[设计规范](设计规范.md) | 横跨多功能的机制 | 机制变化时改 |
| 陷阱清单 | [踩坑约定](踩坑约定.md) | 踩过的坑与通用判据，**编号即身份** | 每踩一次追加到末尾 |
| 历史 | [MAINTAINING.md](../MAINTAINING.md)、[UI-REDESIGN.md](../UI-REDESIGN.md) | 构建环境、闭源依赖、上游 issue、改版提案 | 只读参考，不追改 |

三条边界规则（同一事实写两处必然漂移）：

1. **「该读哪份文档」只在 `AGENTS.md` 写一次**，本文只维护索引。
2. **踩坑叙事只在 `踩坑约定.md`**；功能文档里遇到坑只写编号引用，不复述。
3. **同一话题只留一份权威文档**：功能现状以 `modules/` 为准，`MAINTAINING.md` 里的同名章节视为历史记录。
   发现两份讲同一件事就合并，不要「两份都更新」。

## 闭源依赖

`SuperControls.Style`、`CommonNet` 是随 GPL 分发但源码未公开的程序集；
`SuperUtils` 已用源码重建（`Jvedio-WPF/Jvedio.SuperUtils`），USN 文件枚举等也改为自研实现。
风险与替代路径见 [MAINTAINING.md](../MAINTAINING.md)「闭源依赖」节与 [闭源依赖替换](闭源依赖替换.md)。
